# macOS app releases

Welcome to the public iO repository — here you’ll find release downloads and Sparkle update feeds for macOS. Note: this is not a source-code repository. Source and publishing tools are maintained separately on Gitea.

**App available:**
- *UpgradeKit Test* — a minimal macOS app for validating Sparkle updates, version 0.1.1 build 2.
  - macOS 12 or later
  - Intel and Apple silicon
  - Signed with Developer ID and notarised by Apple
  - Update archives include Sparkle EdDSA signatures

For installed apps, use **Search for updates** from the app menu — no GitHub account is required to download. Please note: this is a *test app* — not a general-purpose updater for other apps.
